# Bobber Begone Next
Fabric client mod for 1.21.2+ that removes the bobber/fishing hook overlay when you get hooked by yourself/another player

Also has a few more features related to the bobber:

## Features
- Completely hide or make the bobber overlay translucent (configurable opacity)
- Shows a small bobber icon next to the crosshair when you're hooked (size and location configurable)
- Use a keybind to toggle bobber visibility

### Original mod (1.15-1.19.4)
The original versions of Bobber Begone Next were adapted from [nu11une's version](https://github.com/nu11une/bobberbegone) for 1.15-1.19.4. If you are looking for those Minecraft versions, please check out the [original mod page](https://modrinth.com/mod/bobber-begone)!

But, Bobber Begone Next now has a lot more features than what the original mod offered.
