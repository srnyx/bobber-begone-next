# Bobber Begone Next
Fabric client mod for 1.21.2+ that removes the bobber overlay when you get hooked by yourself/another player

## Original mod (1.15-1.21.1)
This mod was originally made by [nu11une](https://github.com/nu11une/bobberbegone) for 1.15-1.19 (works up to 1.21.1). If you are looking for those versions, please check out the [original mod page](https://modrinth.com/mod/bobber-begone)!
